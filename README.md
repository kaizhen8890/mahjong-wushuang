# 麻将无双

**和朋友围坐一桌，也能一个人尽兴做牌。**

麻将无双是一款面向 Android 手机与平板的日本麻将应用，将实体麻将计分、技能卡玩法和虚拟麻将放在同一个 App 中。线下聚会时，用平板作为中央计分台、手机作为个人遥控器；想直接打牌时，也可以进入虚拟牌桌，单机试打或与同一 Wi-Fi 下的朋友联机。

[下载 Android 安装包](https://github.com/kaizhen8890/mahjong-wushuang/releases) · [反馈问题与建议](https://github.com/kaizhen8890/mahjong-wushuang/issues)

## 实体麻将：把平板变成桌上的计分台

拿出实体麻将，剩下的记录交给 App。

- 在中央牌桌查看各家点数，记录立直、和牌、流局及对局历史。
- 使用和牌录入与算番功能辅助结算，减少手工计算。
- 玩家通过手机加入房间，绑定自己的座位，进行个人操作。
- 支持普通计分，也可以开启无双玩法，让技能卡加入牌局。

实体计分台适合平板横屏或竖屏使用，个人遥控器适合手机。

## 无双玩法：给牌局加入技能与变数

42 张内置技能卡涵盖单体、团队、攻击、陷阱、环境与神卡。搭配阵营、技能效果和专属演出，让朋友间的牌局多一些变化。

- 查阅完整卡面、效果说明，管理技能手牌并记录技能发动。
- 使用硬币、骰子或轮盘辅助随机判定。
- 体验环境变化、神卡与和牌演出。
- 在支持 NFC 的设备上，扫描已写入对应地址的卡片，进入技能准备页面。

部分技能需要玩家按照卡面说明在实体牌局中手动执行，App 提供记录与辅助操作。NFC 扫描后仍需确认发动；写卡方法见 [NFC 使用指引](docs/nfc-card-codes.md)。

## 虚拟麻将：单机试打，也能同桌联机

直接在 App 内摸牌、打牌与和牌，支持平面与 3D 牌桌。

### 想做什么牌，就朝那个方向打

单机默认采用“配合做牌”模式。人机会配合玩家供牌，方便你做出自己想要的手牌。

- **指定供牌**：选择希望人机打出的牌，并指定由哪一位人机供出。
- **保留牌**：让人机避免打出所选牌种，随时调整或取消。
- **天顶星手牌**：可选开启，以七类役满牌型为起手模板，让大牌更容易来到手中。

天顶星每局等概率选择大四喜、国士无双、九莲宝灯、小四喜、绿一色、四暗刻或大三元模板，再对每张起手牌独立以 **12%** 概率随机替换。它带来接近役满的开局，最终牌型与和牌仍按牌局规则判定。

### 自己决定这一桌怎么玩

单机开局可选择三人或四人麻将，调整起始点数、击飞设置与人机模式。想和人机正常对局时，可以切换到“普通人机”；它具备基本组牌、立直和和牌能力。打开对局设置或供牌面板时，牌局与计时会暂停。

也可以创建局域网房间，邀请同一 Wi-Fi 下的朋友加入虚拟牌桌。供牌与天顶星手牌属于本地单机功能。

## 换上自己的角色和表情

- 选择角色，或导入自己的头像与立绘。
- 导入静态表情，按分类整理、收藏，并在房间中发送。
- 导出角色与自定义表情包，方便备份或转移到另一台设备。

公开安装包的内置表情库为空，可以在 App 内添加自己的图片。使用方法见 [表情库说明](docs/emote-library.md)。

## 下载与开始使用

1. 前往 [GitHub Releases](https://github.com/kaizhen8890/mahjong-wushuang/releases)，选择一个版本，在 Assets 中下载公开 APK。
2. 在 Android 设备上安装；如系统提示，请允许用于安装的浏览器或文件管理器安装该应用。
3. 打开 App，选择实体麻将计分台、手机遥控或虚拟麻将，按页面提示开始。

联机时，请让所有设备安装同一版本，并连接同一个 Wi-Fi。访客网络或路由器的设备隔离设置可能阻止设备互相连接。

对局记录与自定义内容保存在各设备本地。更换设备或卸载前，请先使用 App 内相应的导出功能备份。当前提供 Android 版本，具体更新内容见各版本发布说明。
