# 角色素材

`manifest.json` 是内置角色素材清单。`id` 是稳定标识，不应因改名或换图而改变。每个目录下的 `avatar.png` 是用户提供的头像原图，`portrait.png` 是由对应全身立绘去白底生成的透明 PNG。

新增内置角色时，创建新的小写英文 ID 目录，加入头像和透明立绘，并在清单中增加一项。游戏中的玩家昵称与角色名应分开保存；角色选择引用 ID，立绘只用于展示，不进入规则引擎状态。

用户导入角色应保存在独立的设备素材库，并使用内容指纹识别图片。联网房间只在对方缺少图片时传输分块素材，消息中只使用角色 ID、指纹和小尺寸元数据，不传整张图片。旧存档没有角色信息时使用默认外观。

现在角色库已接入界面。要增加内置角色，只需建立 `public/characters/<id>/avatar.png`、`portrait.png` 并在 `manifest.json` 添加 `id`、`name` 和两个路径；已有 ID 不要改动。用户角色可在选角框中导入头像和立绘，调整头像裁切，导出或导入角色包，也可替换当前自定义角色素材。图片缓存独立于实体对局存档和虚拟房间检查点；删除应用数据会同时删除设备上的自定义素材。
