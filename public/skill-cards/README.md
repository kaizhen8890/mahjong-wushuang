# 技能卡图与动画扩展

这里的 41 张 PNG 从用户提供的《麻将技能卡设计.pdf》完整渲染并裁切，包含卡框、标题、插画和说明；40 个现有技能全部有图。刹那旅程（ID 40）两种卡面均保留，列表第一张为默认。

## 添加或替换图片

1. 将完整卡面 PNG 放入本目录，建议约 720×1008，命名使用稳定的英文或数字，不覆盖其他卡面。
2. 在 `manifest.json` 的 `cards` 数组添加 `{ "key": "new-card", "cardId": 41, "name": "卡名", "src": "/skill-cards/new-card.png", "page": 0, "crop": [], "width": 720, "height": 1008 }`。同一 ID 可以有多个条目，第一项为默认。
3. 新技能的规则资料在 `data/skill-cards.json`，图集不会修改规则。技能 ID 必须一致；卡名变更不影响图片绑定。没有图片时动画显示卡名占位牌，不会崩溃。
4. 运行类型检查和 Android 构建，离线清单会自动打包图集。

`scripts/extract-skill-art.py` 保存了本次 PDF 的可复现裁切方法；它适用于该版印刷网格，遇到不同排版先检查坐标。脚本拒绝覆盖已存在卡图，请先输出到独立目录或备份。原 PDF 不修改。

## 演出触发边界

`lib/presentation.ts` 的 `recordSkillTransitions` 对比操作前后的公开效果：新增公开效果或暗置转公开时生成一次事件；编辑、结束、暗置都不播放。平板本地操作和手机经过验证的操作均走同一入口。环类卡面已切出，但不自行添加用户未指定的环境卡动画。

`app/components/skill-presentation.tsx` 从实际旋转后的名牌测量位置。攻：投向目标名牌、散为红色粒子吸收；团：中央散成蓝色粒子流向所选玩家；单：散成绿色粒子回到发动者；陷：公开触发时中央爆开。多个攻击目标分别落牌，屏幕旋转会更新坐标。减少动态效果设置下只显示简短卡面。

技能演出仅在主机播放，`controller-snapshot.ts` 不向手机发送这些展示事件。所有隐藏效果仍由原有协议投影保护；动画不执行技能规则或修改分数。
