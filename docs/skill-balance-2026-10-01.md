## 本机资料升级

旧版保存整份技能库，直接更新安装包会被旧卡库覆盖。本版 `lib/skill-catalog.ts` 在首次读取旧库时更新上述十张官方卡，移除两张退役卡；保留本机自建卡、图片、随机配置和未调整卡的本机编辑。迁移完成后保存 `skillCatalogRevision`，后续编辑不会每次重启被覆盖。技能库导出带修订号，导入旧库时也会升级。

退役卡从旧对局的技能手牌、牌堆、弃牌堆中移除；已登记的退役效果标记结束，保留历史记录。其他已发动效果的原始快照保持其当时记录。玩家点数、角色、队伍、麻将牌山、设置及对局历史保留。

首次升级前尽量保存原本的完整本机记录到 `mahjong-wushuang:local-state:v1:before-skill-catalog:2026-10-01`；设备存储满时，备份失败不会阻止原对局加载。无需清除应用数据。

## 私人素材构建

公开 GitHub 源码保持 8 张通用 SVG，不包含第三方雀魂表情。私人 APK 在独立目录加入用户本地原有素材后构建，与公开源码使用相同规则。私人素材和含素材的 APK 不应作为公开仓库源码或公开 Release 上传。
