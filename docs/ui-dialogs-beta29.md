# beta29：弹窗 UI 改进第三批

2026-10-12，Android code78。上一批已获用户认可；按最新要求将手机遥控器“选择技能卡”改为一行三张，继续报告 UI-07 流局与 UI-08 手机加扣点。

## 本批内容

- 手机选卡固定三列，沿用完整卡面，调整窄屏卡间距、卡名与勾选标识；保留筛选、检索和返回同卡的配置草稿。
- 流局页改为听牌席位与支付预览两栏，头像、姓名左侧风位、当前点数和听牌状态同时显示。支持全员听牌/全部未听；流局满贯折叠显示。各家增减、结算后点数、庄家是否连庄、本场和供托集中展示；底部确认固定。
- 流局仍使用原 `calculateExhaustiveDraw`、`calculateNagashiDraw` 和连庄规则。连续确认只执行一次，已结算或有无双待结算时说明原因并阻止提交。重新打开时清空未提交的听牌和流局满贯选择；目标退出当前局后，预览和提交均排除失效满贯目标。
- 手机加扣点保留正数金额与加/扣方向分离，头像与箭头显示来源、去向和双方增减；场外明确只改自己的点数。方向切换不带入旧负号，快捷数额、原因输入和原命令格式保留。
- 点数提交期间保留草稿、阻止再次确认与返回；失败就地提示并允许重试。失效目标或零金额不能提交。最终金额与权限仍由牌桌 Host 核验。

## 边界与验证

新增 `draw-settlement-dialog.tsx` 和 `point-flows.css`；修改 `mahjong-console.tsx`、`remote-controller.tsx` 与手机选卡样式 `skill-flow.css`。未修改基础引擎、LAN 协议、暗牌投影、虚拟玩法、技能资料和素材文件。

检查范围包括 320/360/393 像素手机三列、手机横屏、三种平板尺寸；零人/部分/全员听牌、三麻、流局满贯、供托、本场、连庄、撤销；点数四种方向与来源组合、目标失效、失败重试和连续点击。核心回归、上一批交互、成品资源与 Android 构建结果存于本批本地交付目录。

浏览器使用隔离合成数据。真实 Android 返回键、键盘遮挡、覆盖安装、NFC 和多设备 LAN 尚需真机验收。此轮未读写设备已有保存数据。

开发前备份并逐项核对 1304 份真实工程文件，保留原有未提交修改；本批附前后哈希清单和默认只核对的定点回退工具，目标为已接受的 beta28。工程备份不包含设备内个人存档。

公开源码保持 8 张通用表情；98 张私人表情及其他私人资源仅从既有私人构建注入隔离打包目录。iOS 不在当前范围。

后续仍有 UI-09 效果管理、UI-10 分组规则、角色、表情、技能编辑、房间与虚拟页面等条目，未将本批标为全报告完成。
