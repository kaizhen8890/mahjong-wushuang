# Android beta46 / code95

## 本版变化

- 单机3D试打新增开局设置：三人／四人、起始点数、击飞，以及默认关闭的天顶星手牌。打开对局设置和供牌面板时暂停计时与本地操作。
- 默认配合做牌模式支持指定人机供牌、保留牌及取消指令；另可选择能简单组牌、合法立直及和牌的普通人机。
- 天顶星手牌每局等概率选择七类役满模板：大四喜、国士无双、九莲宝灯、小四喜、绿一色、四暗刻、大三元。庄家起手14张；闲家随机减一张后13张。实际起手牌逐张独立以12%概率从剩余实体牌中随机替换，允许回抽同种牌，实体牌和赤牌守恒。三麻只使用合法牌种。
- 虚拟和牌演出的玩家名移至左上，役满文字移至左下，保留原始大字号并允许覆盖立绘。
- 实体对局台技能发动面板明确卡牌行高，保留三列排序；平板列表单独滚动，低高度窗口整栏滚动，避免卡面挤压重叠。
- 离线缓存由正式beta45的v47升级至v48。

功能说明见 [本地虚拟麻将](local-virtual-play.md)。

## 渠道与兼容

公开版不含内置表情，应用内导入与发送功能保留。私人素材和私人APK不公开。两种渠道均沿用已有包名和签名；升级时保留应用数据，不需卸载。平板和手机建议使用相同版本。

“正式交付”表示完成本地交付流程。当前APK仍为既有管线的签名debug构建，beta标签不代表应用商店稳定release构建。

## 验证范围

本版开发阶段通过76项核心测试、30项构建故障测试、类型检查、网页与Android验证构建、签名和完整包内资源核验。单机设置、供牌、天顶星手牌、结算演出和技能卡布局已完成相应浏览器检查；正式包另由交付管线重新核验。

Android真机覆盖安装、返回键、设备性能、双设备联机及NFC没有在本轮实测。技能卡堆叠没有在桌面浏览器修改前完整复现，仍需在用户平板的WebView确认修正效果。
