# beta25：中央风盘、名牌与环境浮窗

> 2026-10-10 文档核对：当前中央实体对局台仅按平板横竖屏设计；本文当时做过的手机尺寸检查是历史证据，不是后续中央桌验收要求。风位最新为左侧放大路径 SVG，见 [beta26风位记录](player-wind-marks-beta26.md)。


2026-10-09。版本 1.1.0-beta.25，Android code 74，离线缓存 v31；实体协议保持 8。

## 本次确认后的界面

- 名牌删去立直、已和牌、已退出及技能效果文字行，避免固定高度将标签压成残缺横线。保留已有颜色、透明度、操作入口，状态仍可供读屏识别；效果详情仍可从原效果入口查看。点数占用释放后的空间，六位数、负数和滚动变化中的中间数字都按实际可用宽度缩放。
- 中央风盘移除“XXX · 当前操作”按钮。环境入口仅显示居中卡名，字号根据框宽测量；去掉“查看环境”。牌山数值扩大，左右加减键缩窄并拉长，保留触控命中空间和原加减/直接录入行为。
- **按第二轮反馈，牌山数字使用原 UI 无衬线字体**，只放大字号；不使用名牌点数的 Georgia 字体。
- 灯的尺寸、方向和圆角保持原样。未亮时为带细纹理和反光的灰色灯罩；普通当前操作为金黄呼吸灯；已立直者为常亮的红色呼吸灯，优先于当前操作色。减少动画模式保持亮色、停用呼吸。此规则替代旧交接中“只有当前方向亮黄灯”的限制。

## 环境操作

六种环境共用新的浮窗容器：只有内容窗带纹理面板，遮罩轻微变暗/模糊，周围牌桌保持可见。标题和关闭入口固定，超短屏内容可滚动；支持点外部、Esc 和 Android 返回关闭，恢复入口焦点。未改动全屏 3D 演出与原前奏/回桌顺序。

魔女审判：主机通过四个头像选择碰牌者，再点一张合法敌方头像直接审判；遥控端固定为自己的身份。取消列表、确认勾选和二次提交，显式点目标即是现实碰牌与审判的确认。请求仍包含 `confirmed: true` 并经过原 Host 的合法目标、阵营、活动状态和环境 ID 校验；不改变任何技能规则。请求等待时锁住按钮并用同步引用挡住快速重复提交，拒绝后保留浮窗与可重试状态；换环境按效果 ID 重建组件，旧回调不会关闭新环境窗口。

**按第二轮反馈，风位、姓名使用更大且清晰的 UI 字体**；候选玩家的身份区与复杂头像分开，使用实底深色面板、亮色姓名和金色风位标记。

规则怪谈突出当前役种与固定 5 番；偶氮玉红突出声明数字及“两张换一宝牌”；宝箱猎人用一次明确的“已翻开指示器”记录按钮；寂静之地主机选择头像后显式记录 −3,000 点，遥控端仍无扣分权限；暗夜显示现有操作说明。原夜间超暗/10 秒闲置熄屏流程保留。

## 验证与交付边界

实际 Host 与遥控组件使用打包 CSS 验证，而非单独静态草图。主机覆盖 1600×1000、1000×1600、393×852、852×393、320×568、1280×800、800×1280，以及六种环境；遥控覆盖手机和平板横竖屏。检查浮窗边界、按钮可用性、头像、字号、六位/负数/滚动点数、牌山 999、环境名、灰/黄/红灯和实际点选裁定。另验证等待/拒绝回复、快速连点、返回与焦点、宝箱重复操作、寂静扣分权限与减少动画。

核心计分、技能规则、Host 权限/快照、虚拟引擎和用户存储未修改；修改前真实文件及保护文件哈希留在任务目录 `work/beta25-backup`。私人资源仍仅注入隔离构建，公开源保留通用表情。
