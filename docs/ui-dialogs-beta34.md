# beta34：共用算番与和牌表单草稿

2026-10-13，Android code83，离线缓存 v40。

- 共用算番分成按牌姿识别与现场算符，复用现有麻将牌图、花纹与色系；显示当前表单符数及自动识别状态。
- 现场算符将九类牌组独立展示，列出雀头、等待、面子、门清荣和及自摸的符数来源。七对子、平和、五番以上沿用原计算规则。只有点采用才更新表单，仍需原有核对与结算。
- 平板切回牌桌再进入时保留本次算符草稿、和牌张、副露标记和自动开关意图；换和牌者或开始下一局重置助手草稿。手机步骤间返回保留，退出后新开和牌按原流程重置。
- 界面草稿与发送给 Host 的和牌数据分开。高于 110 的已有算符结果也能在基本情况的符数选择框显示。
- 无双专属重组继续仅使用牌姿识别，保留原记录方式和专属计算上下文。

本批未修改基础算番引擎、Host 校验、暗牌投影、技能执行、协议和保存格式。公开工程保留 8 张通用表情；私人素材只进入隔离构建。

备份、前后对照、验证日志和本批定点回退工具保存在本地第八批交付目录。浏览器使用隔离样例；实际 Android 返回键、字体缩放、软键盘、安全区和多设备 LAN 仍待实机验收。
