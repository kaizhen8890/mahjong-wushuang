# beta36：阵营模式自摸不向队友收分

2026-10-14，Android code85，离线缓存 v42。

用户实机发现阵营模式自摸仍扣队友分。原因是共用支付函数只按活动玩家筛选，没有接收阵营开关。

- 实体平板预览/结算、手机经 Host 预览/提交，均由当前牌桌设置决定阵营规则。自摸免除同阵营队友的牌点与本场费；对手原份额不因免付而增加，三麻自摸损/补偿仍先沿用普通规则。
- 固定技能额外得点按原语义由实际付款对手合计支付，队友免付；供托照常给和牌者。已退场对手不重新参加付款。
- 实体流局满贯复用自摸付款，也遵守队友免付。荣和付款方式保持，关闭阵营模式仍为普通支付。虚拟日麻不启用实体阵营开关。
- 手机核对页付款方沿用 Host 提供的敌我标记筛选，没有新增协议或暴露他家分数。设置与付款说明同步更新。

新增回归覆盖庄家/闲家、28 种人数/组队/三麻组合、本场/供托/额外点数、自定义队伍、阵营关闭、退场、连续血战、Host 预览/提交/历史/私有演出和流局满贯。原普通流局满贯测试显式关闭阵营；原演出测试按默认开启阵营更新队友零变化断言。
