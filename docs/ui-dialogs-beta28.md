# beta28：弹窗 UI 改进第二批

2026-10-12，Android code77。继续 2026-10-10 审查报告的 UI-03、UI-04、UI-05；本批并未完成全部 20 项。

## 页面与交互

- UI-03 技能选择与配置：平板左侧按类型/名称找卡，右侧配置使用者、目标与效果；手机分为选卡、配置两步，返回选卡后再次选择同卡保留草稿。持续范围与补充说明折叠，提交按钮、错误反馈固定在底部。神卡和麻将无双仍进入原专属页面。
- 按用户纠偏直接使用完整卡面：旧默认内部插画映射到 `public/skill-cards/manifest.json` 的完整卡图，不裁切、不叠加另一套卡片背景。保留平板本地上传图片和已选卡面版本；遥控端仅按已知 id/名称加载自身内置卡图，不接收自定义图片字段。卡面印刷内容可能属于旧版本，配置区仍展示当前技能资料中的效果说明。
- UI-04 和牌录入（部分）：手机三个步骤命名为“基本情况、牌姿与役、核对提交”，返回逐步退回并保留输入。核对页优先显示番、符、役和加番来源，宝牌/技能修正可展开调整；请求中防止重复提交，失败保留草稿。手动选役仍可不录完整牌姿；没有额外强制十四张牌。
- 平板和牌页把可选牌姿收起，确认前新增核对页，展示付款方、逐人点数变化与结算说明；返回修改不记账。原算分和写账函数继续负责结算。
- UI-05 听牌查询：吃、碰、明杠、暗杠直接点选整组牌，支持重选与删除；显示还需录入的手牌数量和“打哪张 → 听哪些”。相同牌合计最多四张，三麻只提供一万、九万。查询保持本机计算，不发送手牌。振听和有役判断不在该查询器范围。
