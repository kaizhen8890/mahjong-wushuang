# beta30：弹窗 UI 改进第四批

2026-10-12，Android code79。在用户接受 beta29 后，按最新要求完成技能卡稀有度排序，继续报告 UI-09 效果管理和 UI-10 规则分组。

- 选卡页按普通、稀有、史诗、无双排列；同稀有度内按单、团、攻、陷、环、神集中，同组保留编号顺序。主机与手机共用显示排序，筛选后维持顺序。手机仍一行三张，完整卡面保留；卡名下显示稀有度与类型。未标注和未知稀有度排在已知稀有度之后，不改原资料、卡堆或抽卡概率。
- 遥控目录新增可选文字字段 `rarity`，有长度与类型校验；旧目录仍可解析，旧主机缺失此项时仅对本地内置编号和名称同时匹配的卡片补全。自定义卡以主机传来的稀有度为准，修改稀有度更新目录缓存版本。未传输卡面、手牌或其他暗置陷阱。
- 场上效果使用完整卡面缩略图、来源到作用对象、状态和持续标签；长说明可展开。主机仍按原视角分组，手机只读取原投影内与自己有关的效果。未揭示卡不渲染卡名、卡面或效果说明。
- 补齐主机无目标效果的“我发动的待处理效果”分组，避免未指定目标的无双已计入数量却列表为空。无双待结算仍只能由专属页面完成，普通管理不能结束。
- 效果管理显示解除影响，手机从列表进入核对页后确认结束；已发生的点数保留。揭示陷阱明确公开给所有人、实际影响所选玩家；空目标或退出本局目标阻止提交，等待期间不能重复提交，失败保留输入。强制通知仍须明确确认，按已有公开效果可匹配卡面。
- 新对局规则按对局、玩家与角色、无双与技能、高级分组，保留原选项和草稿逻辑。顶部显示人数、开局点数、牌山；核对页展示玩家头像和每项改动的前后值。最后确认才建立新局，取消不更改对局，原撤销路径保留。独立音乐面板仍立即生效。

开发前已备份并逐文件核对 1307 份真实工程文件，保留此前未提交修改；交付目录提供定点回退清单，目标为用户已接受的 beta29。工程备份不含设备内存档，本次未操作真实设备数据。

验证与截图使用隔离合成数据；核心测试包含目录往返兼容、排序不修改源卡库、稀有度更新、暗置投影边界。浏览器覆盖手机三列、平板横竖屏、草稿取消与开局撤销、效果管理和陷阱提交；构建结果和详细检查存于本批本地交付目录。真实 Android 返回键、键盘遮挡、覆盖安装、NFC 和多设备 LAN 仍需真机验收。
