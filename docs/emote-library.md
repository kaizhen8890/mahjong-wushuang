# 表情库使用与开发

实体手机遥控器和虚拟牌桌共用表情库。公开版内置表情清单为空，应用内导入资料仅保存在设备本地，不会自动写进公开仓库。

## 在应用内添加

1. 打开表情面板，选择“管理 / 导入”。
2. 输入分类名并新建分类，或选择现有分类。
3. “导入图片”可选择一张或多张 PNG、JPEG、WebP；最多一次 80 张。图片处理为静态表情，保留透明区域。
4. 管理模式下可改名、移动分类、调整分类顺序，或移出自己的表情库。
5. 点击星星收藏；左侧“收藏”“最近”“全部”“内置”及自建分类用于快速筛选。搜索按名称筛选。

完成管理后，点击图片发送；长按连发，松手或滑动列表停止。收藏星星独立于发送按钮，不会误发送表情。只有成功提交的表情才记入最近使用。

“导出当前分类”生成 `mahjong-emotes.json`，包含自定义图片及名称、分类。“收藏／最近／全部／内置”下导出全部自定义图片；在自建分类下只导出该分类。导出不包含内置素材、收藏和最近使用记录。另一台设备用“导入表情包”导入此 JSON。

收藏、最近及分类是本机偏好。卸载或更换设备前，按分类导出备份。移出自己的表情不清除角色素材或对局存档；接收缓存之后会按容量淘汰。

## 图片与容量

- 输入：静态 PNG、JPEG、WebP，单文件不超过 12 MB，解码像素不超过 4000 万。
- 应用导入时保持比例、缩小至最长边 384 像素；压缩后每张最多 256 KiB。
- 表情包与联网接收：解码后最长边不超过 512 像素，校验实际图片和 SHA-256。
- 自有库最多 500 张、50 个分类；单个导出包最多 80 张、28 MB。
- 第一版不导入 SVG、GIF 或动态表情。私人版随包表情仍按独立内容声明提供。

只导入自己制作、获得授权或允许使用的素材。发布表情包前另行确认分发权利。

## 同房间同步

第一次发送自定义表情时，先同步到 Host，再由 Host 按需发送给同房间设备；之后使用缓存。实体与虚拟 LAN 都支持，单机无需传输。

传输使用独立的 offer／request／chunk／ready 消息，先检查房间、协议和已绑定身份，再接收图片。每帧限制 32 KiB，图片限制 256 KiB，校验哈希、格式与尺寸。每次连接最多同步 100 张，最多 4 张同时等待发送确认；超时或断线可以重新发送。

接收别人发送的图片只用于显示，不自动加入自己的表情列表，也不会修改自己的收藏。缓存与角色图片分开存储，最多保留约 100 张未加入自有库的图片。

首次传图在牌局传输队列之外进行，不等待图片才发送摸打／计时／局面。旧局面或已离开的设备不再收到延迟表情。实体的暗夜之战、寂静之地暂停表情交流。

所有设备建议使用同一新版本；旧 v1.0 APK 不支持本轮自定义图片传输。协议版本以lib/lan-protocol.ts和虚拟房间协议常量为准。

## 文件与扩展位置

| 文件 | 作用 |
| --- | --- |
| `data/emotes.json`、`public/emotes/` | 公开版空清单；私人版由工程外bundle叠加 |
| `lib/emote-library.ts` | 自有库、分类、收藏、导入导出、动态图片登记 |
| `lib/emote-media.ts` | 独立 IndexedDB `mahjong-emote-media:v1`，图片与缓存上限 |
| `lib/emote-transfer.ts` | 已认证连接的按需传图与校验 |
| `app/components/emote-picker.tsx`、同名 CSS | 实体和虚拟共用选择面板 |
| `app/components/repeat-emote-button.tsx` | 点击／长按发送行为 |
| `tests/emote-library.test.ts` | 身份、容量、哈希、传图去重与断线边界 |

本机偏好键为 `mahjong-emote-library:v1`。自定义 ID 由 SHA-256 内容生成，前缀 `x-`，不是用户文件名。传输完成前不能发送一个只有 ID、没有可验证素材的自定义表情。

添加内置素材的源码教程仍见 [data/EMOTES.md](../data/EMOTES.md)。不要把用户的 IndexedDB、本机导入包或旧版权素材提交到公开仓库。

## 当前验证范围

自动测试验证真实 PNG 字节的双向传输、认证拒绝、哈希及尺寸上限、并发去重、缓存复用和断线取消；解码器在该协议单元测试中使用固定尺寸替身。桌面浏览器使用实际图片解码，检查了导入、改名、分类、收藏、最近使用、重开保存、导出内容与再导入。

尚需 Android 真机检查文件选择器、下载／分享、跨设备首次传图、断线及缓存恢复。桌面内嵌浏览器没有提供下载完成回执；检查已生成的 JSON 内容及重新导入成功，不据此声称原生下载／分享已经测试。
