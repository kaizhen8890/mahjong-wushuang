# 曲绘唱片播放器

现行核对：2026-10-10 / beta26。唱片与双语歌词在beta21加入，三首歌/新卡面在beta22加入，牌桌自动歌曲优先级在beta24加入。下列原beta21验证记录保留其版本范围，本次文档更新未重新执行。

## 当前界面

根据用户标注删除私人听音室/光晕品牌、冗余说明、双声道仪表和累计时间显示、快退/快进英文标签、歌词窗表头/页脚、重复时间及底部常驻说明。错误与自动播放提示只在实际出现时显示。保留返回、播放暂停、前后十秒、进度、音量、静音、单曲循环。

双盘带改成单张圆形曲绘唱片，使用用户提供的 VOCALOID_setsunatrip.webp：CSS 圆形裁切、黑色唱片纹、金属外沿和固定高光。原 WebP 文件不改动、不重新压缩。播放时转动，暂停保持角度；减少动态效果时停止旋转。仪表删除后同步移除 AudioContext 和波形采样，不再占用音频分析资源。

外观继续独立于技能卡设计，可为其他歌曲设置不同曲绘。手机竖屏使用紧凑单列、横屏双列，平板使用双列。小屏仍可纵向滚动，不横向溢出。

## 已接入的歌词

私人包内置用户提供的《刹那旅程.中日双语.lrc》，47 组时间点、94 行原文，日文上、中文下，当前句居中且译文突出。时间轴和翻译文本均沿用用户文件，不在此版本中重新人工校轴或改译。

LRC 是运行时源；ASS 用于交叉核对，已保留原文件和备份，不引入视频字幕字体/样式，也不执行其中任何内容。首次歌词时间 28.39 秒，末句开始 220.09 秒。LRC 无结束时间，因此末句保持至播放结束；ASS 的末句结束为 220.29 秒，本次不拿该值截断 LRC。

支持多时间戳、毫秒/小数、offset、同轴双语和空白间奏。支持拖动和点句跳转：大幅跳转立即定位，邻句正常推进平滑滚动；窄屏长句换行，旋转屏幕重新居中。实际选句始终以音频 currentTime 为准。

## 私人素材和扩展

音乐身份支持 trackTitle、artist、audioSrc、coverSrc、lyricsSrc。coverSrc 与卡面 artwork 分开，曲绘只接受本地 /audio/nfc/ 的 webp/png/jpg/jpeg/avif；歌词只接受同目录 .lrc。卡片不能提供任意媒体 URL。

刹那旅程在私人隔离构建目录中的设置：
- audioSrc: /audio/nfc/setsuna-trip.mp4
- coverSrc: /audio/nfc/setsuna-trip-cover.webp
- lyricsSrc: /audio/nfc/setsuna-trip-bilingual.lrc

歌曲、曲绘与歌词素材只在私人 APK 的隔离目录内，公开注册表继续为空音源，没有复制私人歌曲、曲绘或翻译歌词。现有 NFC 代号与写入内容不变。对局音乐拦截、返回停止、后台暂停与用户数据保持原行为。

## beta21 阶段验证记录

类型检查、静态检查、核心回归、生产网页和 Android 构建通过。正式 CSS 实测 393×852、852×393、1600×1000、1000×1600、320×568、1280×800、800×1280。覆盖全部 94 行歌词保持一致、首句/最长句/末句居中、点句与拖动跳转、曲绘加载、暂停停转、删除项确实消失、所有播放控件、冷/热 NFC 事件、去重、系统返回、隐藏启动、后台暂停、减少动态效果、对局拦截、自动播放失败手动恢复以及曲绘丢失回退。

包内歌曲/曲绘/LRC 与原文件以 SHA256 核对，签名与上一版一致。NFC 验证使用模拟桥接事件，新界面仍待真实手机验收。


## beta.22：无双卡音乐 / 2026-10-09

私人构建增加 Desultory Signals 和宿星審判，直接保留用户 MP3 音频字节，曲绘采用用户随后补充的正式图片：宿星审判使用 202107301_mms_innstarreferee.webp 原文件；Desultory Signals 使用 26-10-08-23-22-38.png 并无损转 WebP（RGBA 像素一致）。各自的 LRC 只有一个 00:00.00 时间点，整首固定显示用户指定台词，不伪造逐句歌词：

- 断序杂音：面对它，击溃它！
- 宿星审判：真希望还能在哪里……再见一面啊……

沿用唱片转盘、暂停/快进/进度/音量/循环和后台暂停行为。新增刹那旅程二代特别卡面复用已有音频与双语歌词，不复制音源。前台对局判断与“技能当前能否发动”分开：禁用技能时仍留在技能流程，不能误播放音乐。原生 NDEF 外部唤起明确携带 external 来源，前台 Reader Mode 携带 foreground 来源。

同版暗夜之战：平板初始熄屏，轻点只唤醒超暗操作界面，不结束效果；约 10 秒无操作再熄屏，触摸/拖动/键盘输入重新计时。熄屏时遮罩拦截操作并禁用后方焦点；唤醒后恢复操作。长按 3 秒仍可明确结束暗夜；新一轮暗夜重新熄屏。

## 当前音乐分流与维护

三首歌曲只在私人暂存的 `public/audio/nfc/` 加入。新增两首分别是 `desultory-signals.mp3` / `astral-judgement.mp3`，封面分别 `desultory-signals-cover.webp` / `astral-judgement-cover.webp`，单句字幕分别 `desultory-signals.lrc` / `astral-judgement.lrc`。公开注册表 audioSrc 仍为空，无私人媒体；MW-006 二代刹那特别卡复用刹那三份素材，不替换普通/旧特别卡。

断序/宿星前台对局中扫码进入技能准备页；对局外或 Android 外部 NDEF 唤起播放歌曲，即使上次离开停在桌面。两张刹那特别卡正常前台对局中的音乐拦截保留。精确规则见 [NFC 指引](nfc-card-codes.md)，代号不显示在播放器或卡面提示里。

牌桌内另有自动歌曲通道：断序/宿星的代码前奏、3D影片与回桌尾段全部自然结束后播放一次，暂时接管立直音乐；结束后若仍满足立直条件，恢复原曲与位置。跳过、失败或后台中断演出不启动；遥控端与预览不接歌。用户打开独立播放器时暂停牌桌自动背景音乐，关闭后按条件恢复；细节和测试范围见 [beta24 调度记录](cinematic-compression-and-music-beta24.md)。不要混淆独立播放器的返回停止/后台暂停与牌桌歌曲的生命周期。

播放器继续适配手机及平板横竖屏。用户“只看平板”的最新要求针对中央实体对局台，不针对这个共用页面。样式维持拟真材质及曲绘唱片，不恢复已经删除的品牌、仪表与冗余标签。当前最终 Android 播放/NFC/后台行为仍待对应设备验证，桌面事件模拟不等于真机。
