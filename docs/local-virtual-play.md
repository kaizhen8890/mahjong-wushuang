# 本地虚拟麻将：配合做牌与普通人机

适用：本地单机 3D 试打。本功能已在源码实现，是否已随安装包交付，以固定工作区 CURRENT 记录为准。

## 开局

进入单机后选择四人／三人麻将、起始点数、击飞和人机模式，再点击“开始牌局”。起始点数支持 1,000 至 1,000,000，须为 100 的整数倍。首次默认四人、25,000 点、开启击飞、配合做牌；三麻默认起点为 35,000，自定义点数不会因切换人数被覆盖。

开局偏好独立保存。刷新会返回开局页并回读偏好，不恢复上一场牌局；存储不可用时仍可用默认值开局。牌桌设置里的“新开一场”可以重新配置，提交后开始新场，不在当前局中改人数或重置点数。

## 天顶星手牌

这是一个默认关闭的独立开关，配合做牌和普通人机均可开启。启用后，每局从大四喜、国士无双、九莲宝灯、小四喜、绿一色、四暗刻、大三元中等概率选一种起手模板，连庄也会重新生成。

庄家以完整14张模板起手；闲家先从完整模板中随机去掉一个位置，保留13张。随后，每张实际起手牌独立有12%概率进行一次随机替换，不强制至少换一张，也不会递归替换。替换从剩余实体牌中随机抽取，原牌先放回库存，允许抽回相同牌种或同一张牌；总牌数、每种四张及赤牌身份保持正常。

三麻仍使用全部七类模板，九莲宝灯仅用筒或索；模板和随机替换都不会加入二至八万。闲家的第一张正常摸牌不额外进行12%替换，后续摸打和供牌照常。

没有触发替换时，庄家可能直接拥有完整役满形，可以按现有规则自摸。天和、地和、双倍或叠加役满由现有引擎判断。这个开关只改变每局的初始手牌，不改变人机强度或计分规则。

更改开关后点击“开始牌局”应用到新的一场；取消配置保留当前牌局。旧开局偏好没有该字段时默认关闭，保留原有人数、点数、击飞和人机模式。

## 配合做牌

配合人机为玩家供牌，不考虑自身手牌收益，不主动和牌、立直或鸣牌。没有指令时以摸打节奏继续；有指令时优先服务玩家。

1. 点击牌桌上方的“供牌”。面板打开期间，对局和计时暂停。
2. 在“指定下一张”选择“下一位人机”或具体座位，再点目标牌种。每次只保留一个待供指令，再次指定会替换之前的指令。
3. 点击“继续对局”。目标人机在自己的下一次合法弃牌时供出该牌一次，随后自动清除指令。选好牌种后更换“由谁供牌”，会立即更新这条待供指令，无须再点一次牌种。
4. 在“保留牌”点选牌种，所有配合人机都避免打出这些牌；再点可取消。“取消供牌”只取消单次指令，“全部清空”同时清除供牌和保留。进入下一局会清除本局指令。

供牌不受人机原有暗手限制。本地 Host 可以在其他人机暗手、活牌山及尚未公开的王牌槽中调配实体牌，再作为正常弃牌打出。玩家手牌和公开牌不会被移动，不增加牌的总数；有可用赤五时优先供出赤五。目标牌全部在玩家手中或公开区域时，面板会显示无可供牌。

明确指定某牌会自动取消对该牌的保留。保留操作包含当前待供牌时，会取消该供牌指令。无法供出的状态会保留现场并暂停，调整指令或保留后继续，不擅自打出另一张牌。

吃、碰、杠和荣和仍由现有规则判定并由玩家操作。四麻需要吃牌时可以指定上家供牌；三麻按现有规则不提供吃牌。指定较后行动的座位不会跳过中间回合，其他人机也会避免提前打掉待供的牌种。

## 普通人机

普通模式不提供供牌和保留。人机只使用自己的可见信息，按简单向听数和进张选择弃牌，在引擎允许时立直、自摸或荣和。当前主要走门清组牌路线，其他鸣牌选择过；不使用外置 AI 模型，也没有胜率或强度承诺。

## 暂停与边界

本地牌桌设置、角色子面板、供牌和新开一场面板都会暂停。玩家倒计时、响应期限、人机调度和自动操作共用暂停状态，最后一个面板关闭后才继续，停留时间不会在恢复时补扣。

本功能不接入 LAN 供牌命令，不改变 LAN 人机策略。React 界面只得到玩家视角和供牌摘要，不得到完整牌山或其他人暗手。原有实体计分和其他保存资料不使用这份开局偏好。

供牌不是网络 RoundIntent。恢复含本地供牌能力的 Host 检查点时，调用方必须显式提供匹配能力；不把它当普通 LAN 存档恢复。产品本期只保存开局偏好，没有加入牌局自动存档。
