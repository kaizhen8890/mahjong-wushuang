# 麻将无双 v1.1 · Android 公开版

v1.1 将 beta46 的功能整理为正式版本，Android versionCode 为96。

## 主要功能

- 实体日本麻将计分台、手机遥控与局域网虚拟麻将。
- 42张技能卡、阵营玩法、技能演出与NFC卡片入口。
- 本地单机可选三／四人、起始点数、击飞与人机模式；打开设置或供牌面板暂停牌局计时。
- 配合做牌支持指定人机供牌、保留牌与取消指令；普通人机另设可选项，具备基本组牌、立直和和牌能力。
- 天顶星手牌默认关闭：每局等概率选七类役满模板，实际起手牌逐张独立12%随机替换。
- 结算役满保留大字号，技能发动选卡保留三列并改善平板滚动布局。
- 支持导入自定义角色与静态表情，公开版内置表情库为空。

本地单机说明见[玩法指南](local-virtual-play.md)。

## 安装与兼容

在本版本发布页的Assets中下载公开APK。平板与手机请使用同一版本并连接同一Wi-Fi；升级时保留应用数据，重要资料请提前导出备份。

APK沿用原包名和签名，仍由既有签名debug构建管线交付。v1.1版本名不表示已转换为应用商店release构建。

## 验证范围

本地私人v1.1已通过76项核心测试、30项构建故障测试、类型检查、网页与Android编译、签名及完整资源核验；公开APK在发布前由相同管线独立核验。

本轮未进行Android真机覆盖安装、返回键、性能、双设备LAN及NFC实测；平板技能卡布局仍需在实际设备WebView确认。已有浏览器证据不替代真机验收。
