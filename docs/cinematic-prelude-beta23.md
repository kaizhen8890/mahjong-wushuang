# 环境卡与无双卡演出 · beta23

> 2026-10-10 文档核对：前奏设计与实现继续沿用，当前本地版本为beta26；中央实体桌只验平板横竖屏，遥控端的手机反馈不受此限制。当前包体与媒体处理见 [安装包体积管理](APK-SIZE.md)。


2026-10-09。以用户本轮要求取代早期动效草案：六张环境卡共用一套前奏；前奏必须在原 3D 影片之前；保留并优化影片后的回桌流程。只改演出，不改变发动、代价、抽签、持续时间、计分或本局结束规则。

## 播放顺序

发动确认被接受 → 代码前奏 → 既有 3D 影片（掷币时包括既有掷币影片）→ 回桌粒子及结果声明 → 原有操作流程。跳过或原生返回结束整段演出，不重掷、不再次结算。后台关闭演出；恢复、重复快照不会补播旧前奏。

`SkillCinematicSequence` 让影片预加载，同时限制所有播放时钟和音频：只有前奏结束才启动。通用影片 hook 与无双、特殊神卡、魔女的独立调度都接入该限制。入口包括真实牌桌、遥控器及技能库预览。

## 动效

- 环境卡：统一 1.75 秒。实际卡面从发动者名牌附近升起，短暂聚光，沿共享裂纹碎开，平面扩散，收束衔接影片。六张仅替换卡面及名称，不新增各卡独立前奏。
- 无双卡：统一 2.10 秒。复用卡面纹理碎片与微粒层；麻将无双采用金色旋聚，断序杂音采用错位切线，宿星审判采用紫白回旋，听天问剑采用纵向蓄势。正反面都使用相同前奏，不显示结果或提前指向结果目标。
- 动作分为快速离位、减速停驻、蓄压、短暂顿帧、爆散、回收；碎片带旋转与折面，粒子拖尾按相邻时刻的位置计算。改用共享顶点的三角切片，裂解前完整覆盖原卡面。
- 3D 后保留角色、声明、目标标记、五张技能牌及「飞」等已有表达。粒子改为实际屏幕坐标的弧线收束、落点圆环和带阻力／重力的余屑；不再用拉伸 SVG 圆或直线粒子替代实际名牌位置。减少全屏白闪，修复断序切线的无效变换；旧影片完全淡出，避免残帧文字与回桌声明重复叠加。
- 环境回桌保留原时长和原交互：魔女裁决、宝箱确认、寂静封印继续使用原流程；初次发动增加统一的短回桌余光。暗夜影片后仍直接进入黑屏，黑屏后不再加亮粒子。原来的轻点唤醒与 10 秒闲置恢复保留。

## 适配与边界

- 实际名牌与中央操作区测量，窗口旋转／布局尺寸变化重新定位。没有实际目标时不伪造玩家落点。
- 遥控器使用 650 毫秒简化前奏；减少动态效果使用 240 毫秒静态过渡。虚拟掷币的手机结果等待包含牌桌完整前奏的时间；实体硬币手选不等待虚拟掷币。
- Canvas 像素比上限 1.5，32 个纹理切片，前奏最多 140 个细粒子；连续慢帧时降低粒子数量。回桌最多 96 条粒子路径，结束后停止绘制。
- 清理动画帧、定时器、尺寸观察、音频与影片；失败仍走既有可跳过的降级页。
- 环境后续裁决／违规扣分／翻牌确认不会重播发动前奏。原有普通技能动画、Host 权威、暗牌投影、NFC 和音乐资源不变。
