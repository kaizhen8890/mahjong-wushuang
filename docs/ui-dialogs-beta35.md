# beta35：手机紧凑录牌界面

2026-10-14，Android code84，离线缓存 v41。

- 保留用户认可的数牌十列、字牌七列；复用现有牌图与麻将纹理。普通竖屏维持原 43px 按钮高度，短横屏使用 36px 紧凑排布。
- 和牌第二步分为录牌、和牌张·副露、役与符，可直接切换。录牌页集中显示固定高度的已选手牌、数量、撤销末张和四行牌阵，避免连点时牌阵随手牌增长移动。
- 点已选牌删除该张，牌阵角标显示当前数量；多张手牌仅在托盘内滚动。短横屏将托盘与牌阵左右排列。三人局继续只提供一九万。
- 不录牌可直接手动选役或现场算符。助手只调整展示分区，识别、符数规则、自动/手动采用逻辑和原核对提交保持。分区间保留同次草稿，新开和牌重置。
- 界面分区状态不写入结算命令；平板共用助手和无双专属重组保持原入口。

基础引擎、实体计分、Host 校验、暗牌投影、技能、协议和保存格式未修改。公开工程保留 8 张通用表情；私人素材仅进入隔离构建。

开发前实际文件备份、对照截图、验证记录和定点回退工具在本地第九批交付目录。浏览器验证使用隔离样例；Android 实际字体缩放、返回键、软键盘、安全区和多设备 LAN 仍待实机验收。
