# 弹窗界面改进第六批 · beta32

Android versionCode 81，缓存 v38。接续 beta31 已验收界面，范围为审查报告 UI-14、UI-15、UI-16。

- 虚拟牌桌设置分显示、声音、操作，当前状态和音量百分比可见，固定返回入口，复用原画质、声音与出牌设置。设置不暂停对局计时。
- 房主调整规则先展示逐项变更；支持草稿返回和放弃核对。沿用原规则校验与 Host 应用命令，应用后仍需重新准备。
- 连接步骤简化为同一 Wi-Fi、选择房间和席位、准备加入。手动地址折叠，实体房主席位加头像，手机连接前仅用原协议提供的风位与占用信息。虚拟席位区分空席、待准备、准备、断线，并说明不能开局的原因。
- 对局记录保留顺序与撤销语义，点数变化以玩家头像与对齐数字展示。最终结算复用角色头像和既有背景，保留阵营、未分配供托、导出，以及原有重置时机。

不修改计分、虚拟基础规则、暗牌投影、连接协议或导出格式。结算头像另存在界面状态中，不加入导出 JSON。公开工程仍只含通用表情；私人资源仅用于隔离 APK。

开发前已备份实际工作区并逐文件核对。验证结果、截图、APK 与定点回退工具保存在本地第六批交付目录；浏览器模拟不代表 Android 真机覆盖安装、键盘、返回键或多机 LAN 已通过。
