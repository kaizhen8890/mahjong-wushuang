# beta27：弹窗 UI 改进第一批

2026-10-11，Android code76。按 2026-10-10 弹窗审查报告分批实施，本批没有完成全部 20 项。

## 本批行为

- UI-02：实体玩家面板显示头像、姓名左侧风位和点数；常用操作置顶，加扣点分区，计时和退出操作收进折叠的管理区；反馈和撤销保留在底栏。复用现有角色、麻将暗纹、招牌及紫金配色。已有记账、立直和参与状态回调保持原有规则。
- UI-06（部分）：对局和技能库导入先读取、校验和预览，确认后才替换；显示受影响范围并提供替换前备份。技能删除显示卡名和清理范围。角色、表情及其他删除流程留待各自批次。
- UI-01（部分）：公共 Dialog、AlertDialog、Drawer 和选角支持 Android 返回事件，嵌套时优先处理最上层；下拉列表先收起。规则与技能编辑的未保存修改需要选择继续编辑或放弃。规则页的角色选择只修改草稿，点击“应用并开始新对局”才提交。
- UI-08（部分）：玩家面板明确显示场外记账或双方转移，并保留一步加扣点；其他结算页面待后续整理。
- UI-20（样板）：新增样式限定在玩家面板、备份恢复与草稿确认；神卡、无双及演出仍沿用专属关闭规则。

## 实现位置

- `app/components/mahjong-console.tsx`：面板、草稿和原有导入应用回调。
- `app/components/data-management-dialog.tsx`：文件读取、预览、备份与确认。
- `app/components/operation-dialogs.css`：本批界面样式。
- `app/hooks/use-native-back-layer.ts`、`components/ui/native-back-close.tsx`：返回事件层级及公共容器关闭动作。
- `app/components/character-picker.tsx`：原生模态选角、焦点归位与返回。

## 已验证与边界

类型检查、改动文件静态检查、`node scripts/test-core.mjs` 和 Android 构建通过。最终 beta27 编译 CSS 下完成 19 项浏览器检查，包括草稿取消/确认、嵌套返回、通知保护、专属无双返回、导入预览/取消/确认/撤销、技能库替换前备份、快捷转移与布局。

实体中央面板检查 1600×1000、1000×1600、1024×768；共用备份页补查 393×852 与 852×393。小高度面板正文可滚动，操作底栏固定。

浏览器使用隔离的合成数据，未操作设备已有存档。浏览器派发 `mahjong:native-back` 只验证页面处理逻辑，不能代替 Android 实机返回键测试。NFC、真实 LAN、多设备同步、键盘遮挡及覆盖安装仍需设备验收。

另直接加载最终打包的 HTML、JavaScript、CSS 和资源，验证玩家面板、加点撤销、备份页和返回事件通过，没有页面脚本异常或失败资源请求；此项仍是桌面浏览器验证。

本批没有修改规则引擎、Host 权威、暗牌投影、LAN 协议或内置素材清单。公开源码继续使用 8 张通用表情；私人媒体仅进入独立构建目录，不进入公开仓库。Android 版本递增至 code76；iOS 不在本批范围。
