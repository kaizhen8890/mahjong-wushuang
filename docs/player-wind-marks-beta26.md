# 玩家名牌风位标识 · beta26

日期：2026-10-09。以当前代码及验证结果为准。

## 本次需求

用户最新明确：中央对局台只供平板使用，之后不处理手机比例；风位须在姓名左侧。仅检验平板横竖屏。

放大实体牌桌四位玩家名牌的风位；不越出边框、不遮挡姓名、点数与摸牌按钮。用 SVG 轮廓消除书法字体的基线偏位。

## 实现

- `public/art/winds/{east,south,west,north}.svg`：提取现有 `public/fonts/Wushuang-Jianghu.ttf` 的东南西北字形，转换为路径。没有 `<text>`、外部字体或位图依赖。
- 使用 FontTools 4.66.1 的 BoundsPen 获取曲线真实边界；等比缩放至 84×84 的最大包围区，笔画边界中心映射到统一 100×100 画布的 (50,50)。保留原字形比例，西/北不会被纵向拉长。
- 风位保持在姓名左侧，遵循原有阅读顺序。姓名适度右移；长姓名省略显示；点数继续按可用宽度适配，并受名牌可用高度约束。
- 风位边框尺寸 44–60 CSS px。庄家金色、其余深红色底框，四个朝向随名牌一起旋转；使用玩家当前风位选择素材，不依据屏幕座位硬编码。
- 摸牌按钮、计时器、牌桌滚动布局沿用本次修改前样式；未为手机增加布局分支。点击风位仍打开原玩家操作。
- 玩家操作按钮保留风位、姓名、点数和状态的可访问标签。装饰性 SVG 不重复朗读。庄家小角标保留。

已删除的立直/已和牌/已退出标签和效果行没有恢复。中央风盘仍用原 UI 数字字体。基础计分引擎、Host 指令权威、暗牌边界和用户存档格式均未变。
