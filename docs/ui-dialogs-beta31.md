# 弹窗界面改进第五批 · beta31

2026-10-13，Android code80，承接已验收的 beta30。聚焦原报告 UI-11（角色）、UI-12（表情维护）、UI-13（技能详情和编辑）。

- 角色选择固定底部确认，复用内置头像、立绘和背景；导入独立成页。头像预览调用实际保存用的裁切函数；角色包先校验预览，明确新增或同编号更新。未保存导入资料离开前确认，错误保留输入。删除自定义角色先核对，仅移除角色库记录，原媒体保留；选角确认之前不调用对局的角色变更回调。
- 正常表情发送页保持图片、分类和收藏。维护页按分类与表情、导入、导出分区；先查看待导入内容再确认，失败保留剩余待办。导出明确范围和数量，只包含本机导入的表情；特殊分类不再误称“导出当前分类”。移除前核对名称；内置素材不可移除。维护面板按需加载。
- 技能详情使用完整卡面、支持放大，软件效果说明、时机、目标、持续、叠加与全部裁定提示分层显示。编辑分成基础资料、卡面素材、随机与高级，固定保存操作。名称、效果和随机规则错误就地显示，图片读取失败保留原图。随机校验与保存仍用既有规则和路径。

本批不改变计分或虚拟 Host 引擎、不扩展暗牌投影、不改变技能目录排序及手机三列。角色、表情数据格式、数据库版本、导入导出格式和既有容量限制保持一致；公开工程仍为 8 张通用表情。私人素材仅覆盖到隔离构建副本。

工程开发前已复制并逐项核对真实文件，保留既有工作区改动。交付目录另附前后截图、验证记录、准确变更清单及只针对本批的回退工具。浏览器验证不替代 Android 真机返回、软键盘、覆盖安装和多设备联机验收。
