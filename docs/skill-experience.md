# 实体技能卡使用与扩展

现行核对：2026-10-10，beta26 / code75 / 实体协议8。本文所述已有实现以当前代码为准，旧记录不自动形成新任务。

本轮功能用于实体麻将的无双模式。平板保存唯一对局状态，手机只能提交自己身份允许的操作。现实手牌、碰牌、违规和翻开指示器由玩家确认；应用不识别或推断现实麻将牌。

## 六张环境卡

同时只有一个环境生效，新环境替换旧环境；本局结束后停止，下一局清理。普通卡片的现实规则仍按卡面执行。

| 环境 | 应用辅助与表现 | 现场确认 |
| --- | --- | --- |
| 魔女审判 | 开场法阵；手机出现“审判”，裁决特效落在目标名牌；目标退出本局，跳过其操作并从后续支付中排除 | 浮窗选择刚碰牌者，再点尚未和牌敌方的头像直接审判，无额外确认步骤；平板可代记，手机只能操作本人 |
| 暗夜之战 | 平板全黑、手机原遥控界面极暗；暂停亮光演出、表情和背景音乐 | 使用者的现实独立光源可照任意位置，包括牌桌及他人手牌 |
| 寂静之地 | 已接 silence/v2 专属影片与静默封印；暂停背景音乐与表情交流，保留必要操作反馈；平板可记录违规 | 选择违规玩家并确认，直接场外扣 3000 点，不设公共池 |
| 宝箱猎人 | 开箱与光粒子；一次“确认翻牌”记录 | 现实翻开宝牌指示器、现实执行四杠不流局。应用不生成虚拟宝牌 |
| 规则怪谈 | 发动时声明一个非役满役种，卷轴演出；结算中该役固定 5 番，替代原番 | 玩家确认手牌满足该役，结算选择该役；开闭门合法性仍受原规则限制 |
| 偶氮玉红 | 发动时声明 1–9，数字演出；结算增加数字牌数量输入 | 人工确认对应数字的牌数，含副露；每两张追加一张宝牌，不重复填普通宝牌 |

魔女审判的淘汰只针对本局。由至少两名未和牌玩家变成只剩一人时，最后一人获得系统额外 **4000 点**，只奖励一次并结束本局。血战中的普通和牌也会检查这一条件。该奖励不从其他玩家扣除。

### 暗夜亮度

应用内画面转黑并压暗按钮；Android 原生插件临时降低当前应用窗口亮度，结束、离开、进入后台时恢复。iOS 仅历史工程，当前不安排开发/验收。浏览器只能压暗画面，不能改变系统背光。LCD 背光、系统通知等仍可能发光。

手机直接使用原遥控界面并叠加极暗滤镜。平板初始全黑，点击只唤醒原桌面超暗操作，约10秒无操作再黑屏；触摸/拖动/键盘操作重新计时，首击不穿透到桌面。长按3秒仍可结束暗夜；浏览器也支持 Escape。光源照射范围按 2026-10-01 版卡面执行。

## 随机技能卡

随机判定是技能卡的可选属性，不替换单／团／攻／陷／环分类，也不修改现有赛季卡牌。技能库增加“随机”筛选；卡片编辑器可设置决斗币、骰子或轮盘。

- 硬币：每枚反面 0、正面 1；1–3 枚，按总和匹配结果。
- 骰子：每枚 1–6；1–3 枚，按总和匹配结果。
- 轮盘：2–18 个结果，正整数权重决定概率，动画扇区使用同一组权重。
- 每个结果可以登记现实提醒／持续效果说明，或自动执行场外增减点数／抽取技能卡。持续效果说明不自动实现现实规则。
- 作用对象为发动者或发动时所选目标。配置中存在目标效果时必须选择有效目标。
- 抽卡不足时只抽剩余技能卡，不产生新卡；点数效果不是玩家间转账。

### 权威与恢复

游戏内掷币由 Host 使用安全随机源判定，客户端不能提供种子或任意结果对象。单枚硬币可显式提交实体正/反选择，由 Host 按已保存配置验证映射，见下文。发动请求带身份限定的 `activationId` 去重。发动时保存随机配置快照，结果及点数先写入平板本机存档，再显示演出与发送局面。重连、跳过动画和恢复存档都不会重新判定。

暗置陷阱不判定、不播放出牌动画，也不向其他手机发送卡片／随机结果；揭示发动时才判定。之后更改或删除技能库卡片不改变已经登记的判定规则。

### 添加新卡

在原技能卡对象增加 `randomRule`，其余卡片字段保持原格式。例如：

```json
{
  "kind": "coin",
  "count": 1,
  "outcomes": [
    {
      "id": "tails",
      "label": "反面 · 不加点",
      "weight": 1,
      "values": [0],
      "effect": { "kind": "manual", "target": "actor", "amount": 0, "text": "按卡面执行" }
    },
    {
      "id": "heads",
      "label": "正面 · 加点",
      "weight": 1,
      "values": [1],
      "effect": { "kind": "score", "target": "actor", "amount": 1000, "text": "场外获得 1000 点" }
    }
  ]
}
```

此对象放入卡片的 `randomRule`，不是整个技能卡文件。硬币／骰子必须完整覆盖所有可能总和，每个总和只能出现一次；轮盘 `values` 留空。结果 ID 唯一，小写英数字与连字符，最长 40 字符。权重 1–1000，结果名最长 40 字；点数绝对值不超过 100000，抽卡数量 1–5，说明最长 160 字。

扩展入口：`lib/skill-random.ts` 校验和判定，`lib/skill-experience.ts` 权威效果，`app/components/skill-experience.tsx` 与同名 CSS 展示。新增自动效果必须同时扩展 Host 校验、存档与测试，不能只在动画结束回调中改变点数。

## 实体决策币与游戏内掷币

点击发动后，单枚硬币技能会出现“正面 / 反面 / 掷币”选择。正反面按实体结果录入，由 Host 依据当前卡片配置映射效果并保存，不再随机抽取；专属卡跳过硬币片段，直接播放对应效果演出。“掷币”继续使用 Host 的安全随机源并播放原有掷币影片。平板与手机均支持；麻将无双、听天问剑和单枚硬币自定义卡适用，多币、骰子、轮盘沿用原流程。

选择前还没有提交发动；返回可以修改目标，取消不会消耗技能或修改点数。暗置陷阱在揭示时选择，使用暗置时保存的配置，其他玩家仍看不到暗置卡或未产生的结果。Host 继续检查身份、目标和重复请求。历史结果保持不变，重启与重复请求不会再次执行；手动结果带 `source: 'manual'` 并在历史中注明“手动录入”。

实体币功能在协议7阶段加入；当前协议为8，平板和遥控器都使用当前兼容版本，不再按历史协议7安装。

## 存储与联网兼容

实体存档仍使用 `mahjong-wushuang:local-state:v1`，旧资料不清空。新增环境、随机结果是可选字段；旧记录按已有卡名提供兼容提醒。未曾声明的旧规则怪谈／偶氮玉红不会猜测参数，可结束后重新发动。

实体 LAN 协议当前为 **8**，平板与所有手机需使用相同新版本。虚拟房间协议仍为 2，其牌山、暗牌、个人 Snapshot 与 Intent 权威规则未改变。

自动测试覆盖环境命令权限、场外扣分、一次奖励、结算辅助、隐藏陷阱、随机去重恢复及联网解析。桌面浏览器检查覆盖暗夜操作、手机审判和布局。浏览器检查不等于真机测试。

## 四神卡与人工执行边界

麻将无双的单/团/攻/陷四张代价一次确认；紧凑抽屉可返回，组牌复用现有智能算番。正面按门清重组，每组指定和牌张，只计牌型役与实际宝牌，不加本场点数，供托整次只领一次；Host 入账只结束当前局，可继续下一局，按使用者庄闲决定连庄。

反面只选一名仍在局敌方，固定三倍满（庄36000/闲24000），使用者记已和牌，其他玩家继续；正常剩余人数判断仍可结束本局。会话版本校验与去重避免旧草稿或双击重复入账。现实牌的重复使用和代价是否支付仍需人工核对。

断序杂音两攻、宿星审判两团、听天问剑两单，现实代价均已补一次确认。用户明确接受其它三神卡的专属目标/持续效果/人工结算/本局结束现状为完成，不要求追加自动机制；默认持续一局，无需锁定。

## 演出与音乐的现行顺序

Host 先接受并保存 → 代码前奏（环境共用约1.75秒、神卡主题约2.10秒）→ 3D影片 → 原有回桌粒子/真实名牌衔接。寂静影片现为v2共6.4秒；决策币v3共10秒、reveal8.25秒，手动正反录入跳过掷币片。

断序/宿星全部自然演出完成后在Host播放对应歌，优先于立直音乐；播完再按当前立直条件恢复。跳过/失败/后台取消演出不启动歌，静默/暗夜仍抑制。见 [压缩与音乐调度](cinematic-compression-and-music-beta24.md)。

环境特殊操作页改为浮窗；魔女审判头像直选；中央桌仅检查平板比例。NFC扫卡只进入准备页，不能绕过上述权限，见 [NFC代号库](nfc-card-codes.md)。拍照识牌计划已搁置，等用户再提出才开发。
