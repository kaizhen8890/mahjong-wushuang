# 对局演出

结算数据立即更新并保存；演出不参与计分计算。
主机记录最多 8 条短期演出，手机快照只包含公开和牌详情及自己的点数变化。
重复快照按演出 ID 去重；重开本局、撤销和离开界面会清理相应演出。
从存档恢复不会重播旧演出。

- 立直：手机和平板均显示 2.2 秒大字，播放低频掠过声。
- 和牌：先显示 3 秒结果，再进行 1.8 秒结算特效。
- v21：等级 → 点数 → 番符／已录牌张／役种 → 小号玩家名。文字、牌张与横幅整体旋转 -3°，统一划入划出。
- 麻将底纹来自用户 background.jpg 的真实轮廓描摹：public/art/mahjong-pattern.svg，无嵌入位图。樱花与花瓣为独立路径 SVG。
- 底纹通过 CSS mask 着色：--win-pattern-color 与 --win-pattern-opacity 控制色彩、透明度；--win-flower-color 控制樱花颜色。装饰只在演出时显示，没有新增常驻动画。
- 手机录入顺序为牌张选择 → 智能役与符计算 → 手动役种。计算器持续挂载，切换步骤不会丢失内部选择。
- 荣和：仅平板在放铳者名牌处落雷，使用用户提供的和了劈雷.mp3。
- 自摸：不落雷。两种和牌都有赢家粒子与绿色名牌。
- 玩家点数、阵营合计及手机自己的点数，在第二阶段从旧值滚动到新值。
- 音乐仍只由主机播放。短和牌音效跟随手机和平板的演出。

表情每个玩家独占一位，最多四位同时显示。手机位置按每次事件随机变化，
平板位置按玩家 ID 锚定名牌，支持屏幕尺寸变化。表情消失后释放定位监听。
