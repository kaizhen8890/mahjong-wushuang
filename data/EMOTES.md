# 添加自己的表情

GitHub 版本不包含原来使用的第三方表情图片。当前 `public/emotes/` 里的 8 张 SVG 是本项目的通用示例，实体麻将遥控器和虚拟麻将共用同一份清单。

## 准备图片

1. 使用自己制作、获得授权或允许重新分发的图片。建议正方形、透明背景，尺寸约 256×256 像素；支持 PNG、JPG、WebP、SVG。不要把未经授权的素材提交到公开仓库。
2. 把图片复制到 `public/emotes/`，例如 `public/emotes/my-cheer.png`。文件名用英文小写、数字和连字符，不使用空格。
3. 编辑 `data/emotes.json`，添加一项：

   ```json
   { "id": "my-cheer", "label": "加油", "src": "/emotes/my-cheer.png" }
   ```

   `id` 必须唯一，使用小写英文字母、数字和连字符，长度不超过 64；`label` 是按钮提示和图片替代文字；`src` 必须以 `/emotes/` 开头并与实际文件名一致。已发布的 `id` 尽量不要改，局域网消息只发送这个 ID。

4. 按照 README 的构建步骤重新打包，将**同一版本**安装到平板和各手机。表情图片不会通过局域网传输，每台设备都从自己的安装包读取素材。

可以直接替换现有 SVG 的图片路径，也可以在清单中增加新项。删除表情时，从清单移除对应项并删除不再使用的图片。实体遥控器支持点击发送和长按连发；虚拟麻将同样使用这份清单。

提交到 GitHub 前，检查 `public/emotes/`、`data/emotes.json` 以及构建产物，确认只包含有权公开的素材。旧的本地 APK 可能仍带有旧素材；更改源码不会自动修改已安装的 APK。
